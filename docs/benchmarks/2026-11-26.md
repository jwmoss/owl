| Thinking | effort `low` | off | on, effort `xhigh` |
| Answer | 256 tokens | 256 tokens | up to 512 tokens, thinking included |
| Prompts | none; [halogen-prompt.py](halogen-prompt.py): 2.6K / 11K tokens | 2K / 8K tokens cut from Maya's docs | 4K / 16K tokens of `recordNNNNNN: alpha beta …` |

halogen checks that each drafted answer is byte-identical to the answer without drafting: PASS on both checkpoints.
Without drafting it writes about 40 tok/s.

## Settings that changed for this run

| Setting | Before | Now | Why |
|---|---|---|---|
| Maya GPU memory reserve | 16384 MiB for every model | **1024 MiB** (Maya's own APU value); DeepSeek models **16384** | With 1024, DeepSeek's engine filled the shared memory and Linux ran out of it; GLM, Hy4 and Inkling keep RAM for the system themselves |
| halogen `HALOGEN_KV_POOL_POSITIONS` | 524288 (14.9 GiB) | **262144** (7.7 GiB) | With 7 NPU models, halogen warned that 128 GB had no room for everything. One request can still use 256K |

For GLM Maya-M-Derisked, the lower reserve moved 1,830 experts from its RAM tier into its GPU pool, the same memory on
this machine: 11,265 experts in memory before, 11,267 now. Its own 16 GB system headroom sets that limit, so it still
reads about 7 experts from the SSD per token.

## Run it again

On the machine, stop all engines first. Each bench needs all of the memory.

```sh
sudo systemctl stop halogen maya strata

# halogen: the image's bench, then the prompt speed while it serves
podman run --rm --device /dev/kfd --device /dev/dri --group-add keep-groups --ipc=host --ulimit memlock=-1:-1 \
  -e HALOGEN_CHECKPOINT=/models/qwen38-flash-next-v2.hgn -e HALOGEN_KV_POOL_POSITIONS=262144 \
  -v ~/models/halogen:/models ghcr.io/peonist-ai/halogen-flash-server:0.20.7 bench

# Maya: the config that Ansible's maya role installed for the model (its maya_marker)
cd ~/src/project-maya && ./maya.sh --bench --config .installed-<commit>-<hash>.json

# Strata: one saved preset per run
strata bench run --profile ~/.local/state/strata/launch/qwen.json --out ~/bench/strata-qwen

# Hash every model file
cd ~/models && find maya halogen strata -type f -size +1M -not -path '*/.cache/*' -print0 \
  | xargs -0 -P 8 -n 1 sha256sum > sha256sums.txt
```

Then make the SBOM: `uv run --no-project python -I docs/benchmarks/sbom.py sha256sums.txt docs/benchmarks/<date>.cdx.json`.
